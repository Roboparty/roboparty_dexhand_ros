# ROS 2 integration has moved / ROS 2 接入已迁移

This repository is retired. Current RP Hand ROS 2 integration is maintained in **[roboparty_dexhand/ros2/rphand_ros](https://github.com/Roboparty/roboparty_dexhand/tree/main/ros2/rphand_ros)**, alongside the C++ and Python SDK.

The current ROS package targets **ROS 2 Jazzy**. For existing Humble / dexhand_py installations, follow the migration guide before replacing packages.

- [RP Hand product documentation, wiring, applications and models](https://github.com/Roboparty/rp_dexhand)
- [SDK source and ROS 2 documentation](https://github.com/Roboparty/roboparty_dexhand/blob/main/docs/ros2.md)
- [Migration guide](https://github.com/Roboparty/rp_dexhand/blob/docs/developer-experience-20261019/docs/compatibility.md)
